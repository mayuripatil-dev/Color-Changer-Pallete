## ✨ About the Project

**Color Changer Palette** is a small interactive game built with plain HTML, CSS and JavaScript. Click one of the five color buttons and the preview card instantly changes to that color, shows the color name, and adds one to your **Colors selected** counter. A **Reset** button puts everything back to the start.

It was created as a DOM practice project to learn how to select elements, listen for events and update the page from JavaScript.

## 🚀 Features

- 🎨 **5 color buttons**: Red, Green, Blue, Yellow and Purple
- 🖼️ **Live preview card** that changes color with a smooth transition
- 🏷️ **Current color name** displayed on the preview
- 🔢 **Score counter** that tracks how many colors you have selected
- ↻ **Reset button** to restore the preview and score
- 🌙 **Dark theme** with hover animations on the buttons
- 📱 **Responsive layout**: 5 columns on desktop, 2 columns on phones

## 🛠️ Built With

| Technology | Used For |
|------------|----------|
| **HTML5** | Page structure with semantic tags (`main`, `section`, `button`) |
| **CSS3** | Flexbox, CSS Grid, transitions, media queries |
| **JavaScript (ES6)** | DOM selection, event listeners, updating text and styles |

## 🧠 What I Learned

- Selecting elements with `document.querySelector()`
- Handling clicks with `addEventListener()`
- Changing styles dynamically with `element.style.backgroundColor`
- Updating text with `textContent`
- Writing a reusable function (`changeColor`) instead of repeating code
- Building a responsive grid with CSS Grid and `@media` queries

## ▶️ Getting Started

1. **Clone the repository**
```bash
   git clone https://github.com/mayuripatil-dev/Color-Changer-Pallete.git
```

2. **Go into the folder**
```bash
   cd Color-Changer-Pallete
```

3. **Open the project**

   Double-click `project.html`, or open it in VS Code and use **Go Live** (Live Server).

No installation or build step is needed.

## 🎮 How to Play

1. Open `project.html` in your browser.
2. Click any color button.
3. Watch the preview card change color and the name update.
4. See your **Colors selected** score go up with every click.
5. Press **↻ Reset Game** to start over.
